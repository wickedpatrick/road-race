# Spain, Portugal, Benelux, Switzerland

## Why

The user, in the evening: "maybe one more country? what's left?" — the rest of batch 2: Spain, Portugal, the
Netherlands, Belgium, Luxembourg, Switzerland with Liechtenstein. Built like Norway/France/Italy: one agent per
group, decisions mine, the user reads the summary.

## Decided (my calls, for the user to check)

- **Spain (es), 30 cities:** Madrid, Barcelona, Valencia, Sevilla, Zaragoza, Málaga, Murcia, Bilbao, Alicante, Córdoba, Valladolid, Vigo, Gijón/Oviedo, A Coruña, Granada,
  Vitoria, Pamplona, San Sebastián, Santander, Salamanca, Toledo, Cádiz, Almería, Badajoz, Cáceres/Mérida,
  Tarragona, Girona, Burgos, León, Logroño, Huelva, Teruel or similar. Autopistas/autovías A-/AP- (express 120),
  N- roads (90, some 100 via the road-part limit), 50 towns. Euro. Blue motorway boards, white others; plates as
  posted (blue A/AP, red N). Polish exonyms (Sewilla, Saragossa, Kordoba, Grenada, Walencja...). Regions:
  comunidades autónomas. Biomes: `mediterranean`, `fields` (meseta, maybe `steppe` for dry plains), `mountains`
  (Pyrenees, Sierra Nevada), `coast`. Bilingual signs where posted (Catalan, Basque, Galician) through
  `native.json` only if simple; else Spanish only. Neighbours fr, pt, ad, (gi); favourite pt.
- **Portugal (pt), ~12 cities:** Lisboa, Porto, Braga, Coimbra, Faro, Évora, Aveiro, Viseu, Leiria, Setúbal,
  Guimarães, Bragança or similar. A-roads (120), IP/IC (100 via road-part limit where posted), N (90). The 25 de
  Abril bridge (`suspension`) or Vasco da Gama (`stayed`/`beam`) on a road into Lisbon. Euro. Neighbour es,
  favourite es.
- **Benelux:** one map like the Southern Balkans (`sb`, `members`), code `bx` with members `nl`, `be`, `lu`, IF
  the existing neighbour codes (de/fr list nl, be, lu) resolve to the member map the way sb's members do; else three
  maps. ~10 Dutch, ~8 Belgian, 2 Luxembourg cities (Amsterdam, Rotterdam, Den Haag, Utrecht, Eindhoven, Groningen,
  Maastricht, Arnhem, Zwolle, Middelburg; Brussel/Bruxelles, Antwerpen, Gent, Brugge, Liège, Namur, Charleroi,
  Leuven; Luxembourg, Esch-sur-Alzette). Limits as posted (nl 100 by day on A roads — use 100, be 120, lu 130).
  Belgian signs: Dutch in Flanders, French in Wallonia, both in Brussels (`native.json` or the region's language).
  Polish exonyms (Bruksela, Antwerpia, Haga, Gandawa, Brugia, Liège/Lüttich...). Windmills, polders, dykes.
- **Switzerland (ch), ~14 cities**, Liechtenstein (Vaduz) as a member part if simple (like sb), else left out:
  Zürich, Genève, Basel, Bern, Lausanne, Luzern, St. Gallen, Lugano, Winterthur, Biel/Bienne, Thun, Chur, Sion,
  Fribourg, Interlaken or Zermatt, or similar. Motorways A1–A13 (120), other roads 80, towns 50. Tunnels: Gotthard road
  tunnel (16.9 km), San Bernardino, Seelisberg. Franc (CHF). Green motorway boards, blue main road boards. Signs in
  the local language (German, French, Italian); bilingual Biel/Bienne, Fribourg/Freiburg. Polish exonyms
  (Zurych, Genewa, Bazylea, Berno, Lozanna, Lucerna). Neighbours de, fr, it, at, li; favourite de.
- Postcards: one per map city, each its own new painter. Texts in pl, en, cs, is, de. Facts neutral.
- Arrival tunes (separate task): Spain Marcha Real (PD) and a folk tune; Portugal A Portuguesa (Keil, d. 1907);
  Netherlands Wilhelmus; Belgium La Brabançonne (Campenhout, d. 1848); Luxembourg Ons Heemecht (Zinnen, d. 1923);
  Switzerland Swiss Psalm (Zwyssig, d. 1854); Liechtenstein shares God Save the King's tune (skip or motif).

## Non-goals
