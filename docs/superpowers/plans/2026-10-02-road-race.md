# Road Race Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wyścig pseudo-3D (styl OutRun / Atari Cross Country Road Race) w Godot 4.7, grywalny w przeglądarce na MacBooku Air (Intel i5, 8 GB).

**Architecture:** Cała logika (paliwo, skrzynia, trasa, ruch, kolizje) siedzi w czystych klasach `RefCounted` bez zależności od scen, więc da się ją testować headless. Jedna scena `Game` rysuje świat w `_draw()` (pasy drogi z projekcją perspektywiczną, sprite'y wektorowe). Menu i HUD to osobne sceny budowane w kodzie.

**Tech Stack:** Godot 4.7.2 (`/Applications/Godot.app/Contents/MacOS/Godot`), GDScript, renderer Compatibility, eksport Web bez wątków, `python3 -m http.server` do lokalnego grania.

**Spec:** `docs/superpowers/specs/2026-10-02-road-race-design.md`

## Global Constraints

- Godot 4.7, renderer Compatibility, eksport Web bez wątków.
- Rozdzielczość logiczna 960x540, skalowanie `canvas_items` / `keep`.
- Brak zewnętrznych assetów: auta i otoczenie rysowane wektorowo w kodzie.
- Auta: Volvo XC60, Toyota RAV4, Toyota Yaris (obecne generacje), widok z tyłu.
- 4 pory roku: wiosna, lato, jesień, zima.
- Odcinki i czasy: Kraków 180 s, A4 300 s, Roztocze 180 s.
- Skrzynia automatyczna, bez biegu wstecznego. Spacja i S/strzałka w dół hamują. Brak hamulca ręcznego.
- Sterowanie: strzałki lub WASD.
- Kolizja jak w Atari: silna utrata prędkości i czasu, bez game over. Przegrana tylko przy braku paliwa lub czasu.
- Cel: stabilne 60 FPS w przeglądarce na zintegrowanej grafice Intela.
- Katalog nie jest repozytorium git: zamiast commitów robimy punkty kontrolne (uruchomienie testów).

## Review Focus

- Gracz jedzie bez gazu: auto powoli zwalnia (toczenie się), nie stoi w miejscu ani nie cofa się.
- Hamowanie przy prędkości 0: prędkość nigdy nie schodzi poniżej 0 (brak jazdy do tyłu).
- Paliwo 0 przy jeździe: gra kończy się dopiero, gdy auto stanie, a nie w chwili wyzerowania baku.
- Stacja minięta bez zatrzymania: nic się nie dzieje, ale stacja nie tankuje „w locie".
- Tankowanie nie przekracza pojemności baku i dolicza czas.
- Jednoczesne wciśnięcie lewo+prawo i gaz+hamulec: brak dziwnego zachowania (lewo+prawo = prosto, hamulec wygrywa z gazem).
- Okno traci fokus w przeglądarce: klawisze nie zostają „wciśnięte" na stałe (reset wejścia przy utracie fokusu).

- [ ] **Step 1: Napisz `project.godot`** z rozdzielczością 960x540, `stretch/mode="canvas_items"`, rendererem `gl_compatibility`, autoloadem `Session` oraz akcjami wejścia: `accel` (W, Up), `brake` (S, Down, Space), `left` (A, Left), `right` (D, Right).
- [ ] **Step 2: Napisz `tests/run_tests.gd`**

```gdscript
extends SceneTree
var failures := 0
func check(cond: bool, msg: String) -> void:
	if cond: print("PASS ", msg)
	else:
		print("FAIL ", msg); failures += 1
func _init() -> void:
	for f in DirAccess.get_files_at("res://tests"):
		if f.begins_with("test_") and f.ends_with(".gd"):
			var t = load("res://tests/" + f).new()
			t.run(self)
	quit(1 if failures > 0 else 0)
```

- [ ] **Step 3: Uruchom runner** (komenda wyżej). Oczekiwane: kod wyjścia 0, brak błędów skryptu.

### Task 2: Skrzynia biegów i paliwo (logika)

**Files:**
- Create: `src/logic/gearbox.gd`, `src/logic/fuel.gd`, `tests/test_gearbox.gd`, `tests/test_fuel.gd`

**Interfaces:**
- Produces:
  - `Gearbox.new(max_speed: float)`; `gear_for(speed: float) -> int` (1..6, nigdy 0 ani -1); `top_speed_for_gear(g: int) -> float`.
  - `Fuel.new(capacity: float, burn_per_sec_at_max: float)`; pola `level`; `burn(dt: float, speed_ratio: float)`; `refuel(dt: float, rate: float) -> float` (zwraca dolane, nie przekracza `capacity`); `is_empty() -> bool`; `ratio() -> float`.

- [ ] **Step 1: Napisz testy.** Gearbox: bieg dla prędkości 0 to 1; dla `max_speed` to 6; monotonicznie niemalejący; nigdy < 1. Fuel: `burn` zmniejsza poziom proporcjonalnie do `speed_ratio` (przy 0 spala bieg jałowy 10% wartości z max); `refuel` nie przekracza pojemności; `is_empty()` przy 0.
- [ ] **Step 2: Uruchom, oczekuj FAIL** (brak klas).
- [ ] **Step 3: Zaimplementuj.** Bieg = `clampi(1 + int(speed / max_speed * 6.0), 1, 6)`. Zużycie = `burn_per_sec_at_max * dt * (0.1 + 0.9 * speed_ratio)`. Poziom nie spada poniżej 0.
- [ ] **Step 4: Uruchom, oczekuj PASS.**

### Task 3: Dane aut i odcinków

**Interfaces:**
- Produces: `CarStats.get(id: String) -> Dictionary` z kluczami `name, max_speed (m/s), accel, brake, tank (l), burn (l/s przy max), handling, body_color, width`. ID: `"xc60"`, `"rav4"`, `"yaris"`. `CarStats.ALL_IDS: Array`.
- `StageData.get(i: int) -> Dictionary` z kluczami `name, duration (s), lanes, length (m), traffic_density, stations (Array[float] dystansów), scenery (String), curve_amount, hill_amount, finish_label`. `StageData.COUNT = 3`.

- [ ] **Step 1: Test:** każde ID auta zwraca wszystkie klucze; `duration` dla odcinków wynosi 180/300/180; stacje leżą w przedziale `(0, length)` i rosną; długość pozwala dojechać przy rozsądnym zużyciu (bak starcza na ~70% trasy, więc stacja jest potrzebna: `tank / burn` przy 80% vmax < czas trasy).
- [ ] **Step 2: Uruchom, FAIL.**
- [ ] **Step 3: Zaimplementuj** dane. Yaris: najlżejszy, mały bak, mała vmax. RAV4: środek. XC60: najszybszy, największy bak, największe spalanie. Odcinki: Kraków `lanes=2`, gęsty ruch, wolne; A4 `lanes=3`, długie proste, szybki ruch, 2 stacje; Roztocze `lanes=2`, zakręty i wzgórza, 1 stacja, `scenery="forest"`.
- [ ] **Step 4: PASS.**

### Task 4: Trasa i projekcja pseudo-3D

**Files:**
- Create: `src/logic/track.gd`, `tests/test_track.gd`

**Interfaces:**
- Produces: `Track.build(stage: Dictionary, seed: int) -> Track`; `segment_at(z: float) -> Dictionary` z `curve, hill`; `project(cam_x, cam_y, cam_z, seg_z, world_x, world_y, screen_w, screen_h) -> Dictionary` z `x, y, scale` (`scale<=0` gdy za kamerą). Stała `SEG_LEN = 5.0`. `total_length`.

- [ ] **Step 1: Test:** `build` jest deterministyczny dla tego samego seeda; `segment_at(0)` ma zerową krzywiznę (start prosty); `project` dla punktu dalej daje mniejszy `scale`; punkt za kamerą daje `scale <= 0`; ostatnie 200 m trasy jest proste (podjazd do mety).
- [ ] **Step 2: FAIL.**
- [ ] **Step 3: Zaimplementuj.** Segmenty z krzywizną i wzgórzami wygładzanymi (ease in/out) z `RandomNumberGenerator` z seedem. Projekcja klasyczna: `scale = cam_depth / (seg_z - cam_z)`, `x = w/2 + scale * (world_x - cam_x) * w/2`, `y = h/2 - scale * (world_y - cam_y) * h/2`.
- [ ] **Step 4: PASS.**

### Task 5: Ruch uliczny i kolizje

**Files:**
- Create: `src/logic/traffic.gd`, `tests/test_traffic.gd`

**Interfaces:**
- Consumes: `Track.total_length`, `StageData.get(i)`.
- Produces: `Traffic.build(stage: Dictionary, seed: int)`; pole `cars: Array` (słowniki `z, lane_x (-1..1), speed, kind`); `update(dt, player_z)`; `check_collision(player_z: float, player_x: float, player_halfwidth: float) -> int` (indeks auta lub -1); `nearest_ahead(player_z: float) -> int`.

- [ ] **Step 1: Test:** ruch zawsze jedzie wolniej niż vmax najszybszego auta; auta nie startują w odległości < 100 m od startu; kolizja wykrywana przy zbliżonym `z` i `lane_x`, brak przy różnych pasach; auta przy końcu trasy zawijają się lub znikają (brak wyjścia poza `total_length`).
- [ ] **Step 2: FAIL.**
- [ ] **Step 3: Zaimplementuj.** Liczba aut = `traffic_density * length / 100`. `kind`: car/van/truck, prędkość 0.25-0.55 vmax najwolniejszego auta gracza.
- [ ] **Step 4: PASS.**

### Task 6: Stan wyścigu (czas, dystans, paliwo, koniec)

**Files:**
- Create: `src/logic/race.gd`, `tests/test_race.gd`

**Interfaces:**
- Consumes: `Gearbox`, `Fuel`, `CarStats`, `StageData`, `Track`, `Traffic`.
- Produces: `Race.new(car_id, stage_index, seed)`; `step(dt, input: Dictionary)` gdzie `input = {accel: bool, brake: bool, steer: float}`; pola `speed, z, x, time_left, state ("running"|"won"|"out_of_time"|"out_of_fuel"), gear, fuel (Fuel), refueling (bool), stats`; `station_in_range() -> bool`; sygnał `collided`.

- [ ] **Step 1: Testy:**
  - Bez gazu prędkość maleje, ale nie schodzi poniżej 0; hamowanie przy v=0 daje v=0 (nigdy ujemna).
  - `accel+brake` jednocześnie: hamulec wygrywa.
  - Dojazd do `length` przy dodatnim czasie => `won`.
  - `time_left <= 0` => `out_of_time`.
  - `fuel` pusty i `speed == 0` => `out_of_fuel`; pusty ale jeszcze toczący się => `running`.
  - Stacja: przy `speed < 3` w strefie stacji `refueling == true`, poziom rośnie, `time_left` nadal maleje; przy szybszym przejeździe nic nie tankuje.
  - Kolizja: `speed *= 0.3` i `time_left -= 5`; brak game over.
  - Zjazd na pobocze (`abs(x) > 1`) ogranicza prędkość do 40% vmax.
  - `steer` lewo+prawo = 0 (obsłużone w warstwie wejścia, test na wartość 0.0).
- [ ] **Step 2: FAIL.**
- [ ] **Step 3: Zaimplementuj** zgodnie z testami. Kierowanie skaluje się z prędkością (`steer * handling * speed_ratio`) i jest zmniejszane siłą odśrodkową zakrętu.
- [ ] **Step 4: PASS.**
